UNIT 01 // THE FACTORY

Write a spec. Get a pull request.

You describe what you want — plain English or structured EDN. Miniforge plans the work, writes the code, runs the tests, reviews itself, and opens a PR. No prompt engineering. No copy-paste. Full SDLC.

GitHub → Quickstart →
PROCESS

The line runs in phases.

A team of specialized agents hands work through the pipeline, like a dev team — with a policy gate at every transition.

  • 01ExploreScans the codebase, loads relevant files, queries the knowledge base.
  • 02PlanDecomposes the spec into a task DAG with dependencies and parallel execution.
  • 03ImplementGenerates code through LLM agent sessions working on your repository.
  • 04VerifyGates: syntax, lint, no-secrets, tests-pass. Failures are repaired automatically, within budget.
  • 05ReviewSelf-reviews the diff against the spec and constraints before anything ships.
  • 06ReleaseCreates the branch, commits, opens the PR with a full description.
  • 07ObserveMonitors the PR for up to 72 hours: classifies comments, fixes feedback, answers questions, merges when ready.
CONTROL

Four nested loops.

Team loop

Agents hand off work

Specialized agents collaborate through phases — explore, plan, implement, verify, review, release — each with its own role and its own constraints.

Inner loop

Generate, validate, repair

Inside each phase the agent generates an artifact, validates it against policy gates, and repairs failures automatically. Budget exhausted → escalate to you.

Observe loop

The PR is not the end

After release, a monitor polls the PR, classifies comments, fixes change requests, answers questions, and attempts the merge on approval.

Meta loop

Governance can halt the floor

Meta-agents watch progress, test quality, conflicts and budgets. Any of them can halt the factory. Every decision is observable and produces evidence.

SAFETY & GOVERNANCE

Governed at every transition.

Policy gates

Explicit quality gates

Syntax, lint, secrets, tests, standards — enforced as blocking gates between phases, not suggestions in a prompt.

Budgets

Hard stops

Token, cost and time limits enforce hard stops. Runaway work escalates to a human instead of burning quota.

Evidence

Traceable decisions

Every decision produces an evidence bundle. What ran, what passed, what failed, and why — recorded and reviewable.

START

Local-first. Apache 2.0.

Runs on your machine or inside your network, directly on your repositories.
